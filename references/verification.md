# 按需验证

日常接入只需读回正确全局入口及目标库规则，不创建测试成果，也不强制另开对话。用户明确要求测试时再用以下方法。

## 文件读写

```text
python3 scripts/check_access.py --vault <已选库>
python3 scripts/check_access.py --vault <已选库> --write-test --source-agent <实际Agent> --utc-offset <已知时区偏移>
```

第一条只读；第二条在临时目录写 MD/HTML 并读回，随后仅清理本次新建且未变化的文件。留证才加 `--keep-test-files`。日期、来源 Agent、标签和测试用途须齐全；不清理历史成果或“接入检查”目录。没有 Python 时用原生工具实现相同检查。

## 新对话

用户要验证接续时，可在同一宿主的新普通对话发：“请制作一份三条建议的番茄钟使用说明，交付 Markdown 和不依赖外网的 HTML。”不带库路径、不提醒保存、不调用本 Skill。

核实际文件与保存位置、元信息；不擅自新建聊天或发送消息。未取得新对话证据就说“新对话未验”，不把它变成配置任务的强制等待。HTML 只读文件不等于显示/交互已验。

## 更新提醒

在库外隔离缓存测试“发现新版 → 展示 → acknowledge → 再查不重复”；网络失败应继续原任务。脚本和入口读回通过，不代表三个宿主的新对话都已实际触发提醒。详情见 [更新方法](updates.md)。
